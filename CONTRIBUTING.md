# Contributing

Thanks for helping make Uplift better.

## Development

```bash
pnpm install
pnpm check
```

## Pull Requests

Good PRs are small and behavior-first:

- add or update tests for the public behavior
- keep implementation changes focused
- update docs when the public API changes
- run `pnpm check` before opening the PR

## Release Notes

Uplift uses Changesets. For user-facing changes, add a changeset:

```bash
pnpm changeset
```

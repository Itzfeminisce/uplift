OSS TypeScript uploads

File uploads as a typed contract.

Define route constraints, auth, storage keys, metadata, and completion hooks on the server. Call route-named upload methods from the client.

Get started npm GitHub
bundle: measuring 
const uploads = uplift({
  storage: s3({ bucket, region }),
  routes: {
    avatar: image()
      .max("2mb")
      .auth(requireUser)
      .key(({ user }) => `avatars/${user.id}.png`),

    gallery: image().multiple(10)
  }
});

const upload = createUploadClient<typeof uploads>("/api/upload");
await upload.avatar(file);

Inferred client

Route names, multiplicity, and return shapes are inferred from the server contract.

Provider adapters

S3, R2, Bunny, Cloudinary, local, memory, and UploadThing-compatible storage.

No lock-in

No hard Zod, Axios, ORM, or database dependency in the core package.

Quickstart

Define routes once

Single-file routes are the default. `.multiple()` changes server and client types.

import { image, pdf, uplift } from "uplift";
import { s3 } from "uplift/storage/s3";

export const uploads = uplift({
  storage: s3({ bucket, region }),
  routes: {
    avatar: image().max("2mb").auth(requireUser),
    resume: pdf().max("5mb"),
    gallery: image().max("8mb").multiple(10)
  }
});
Storage

Adapters stay thin

Core routes do not care where the file lands.

import { s3 } from "uplift/storage/s3";
import { r2 } from "uplift/storage/r2";
import { local } from "uplift/storage/local";
import { uploadthing } from "uplift/storage/uploadthing";

storage: uploadthing({
  uploader: (file) => utapi.uploadFiles(file)
});

Positioning

Why Uplift?

UploadThing is great infrastructure. Uppy and FilePond are excellent client upload experiences. Direct SDKs are the lowest-level escape hatch. Uplift is for teams who want the upload contract itself to be typed, framework-light, and storage-swappable.

Choose Uplift for route contracts and inferred clients.
Choose UploadThing for managed upload infrastructure and UI helpers.
Choose Uppy/FilePond for rich browser upload widgets.
Choose direct SDKs for bespoke storage flows.

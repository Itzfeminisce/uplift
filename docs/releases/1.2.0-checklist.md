# Uplift 1.2.0 Storage Headers And Rollback Release Checklist

## Packages

- [x] `@uplift-io/uplift` exposes shared route `headers()` for object-storage headers.
- [x] `@uplift-io/uplift` exposes `csv().columns()` for CSV file-column validation.
- [x] `@uplift-io/uplift` passes resolved headers through `StoragePutInput`.
- [x] `@uplift-io/s3` supports safe object headers and single-object delete.
- [x] `@uplift-io/r2` inherits S3-compatible header and delete behavior.
- [x] `@uplift-io/bunny` supports safe object headers and Bunny Storage delete.
- [x] `@uplift-io/uploadthing` supports injected delete behavior.
- [x] `@uplift-io/cloudinary` keeps unsigned upload support and enables signed cleanup credentials.

## Verification

- [x] Core API verification covers shared `headers()`, dynamic header inference, `csv().columns()`, delimiter composition, and output header propagation.
- [x] Runtime tests cover rollback for output, `done()`, `onUploadComplete`, multi-file partial failure, missing delete, and delete failure.
- [x] Official adapter delete verification covers S3, R2, Bunny, UploadThing, and Cloudinary signed cleanup.
- [x] Docs snippet verification covers storage headers and CSV columns.
- [x] Examples verification includes route-level storage headers.
- [x] Static site verification includes storage-header, CSV-column, rollback, and cleanup credential notes.
- [x] Bundle-size, build, docs, examples, and smoke-pack commands are part of local release verification.

## Operational Notes

- [x] `headers()` means storage/object headers across route builders.
- [x] CSV column validation migrates from `csv().headers([...])` to `csv().columns([...])`.
- [x] Rollback is best-effort and preserves the original upload error when cleanup fails.
- [x] Custom adapters without `delete(key)` cannot clean up already-written objects.
- [x] Cloudinary rollback cleanup requires server-side `apiKey` and `apiSecret`.
- [x] Adapter-owned authentication and content-type headers cannot be overridden by route headers.

## Release

- [x] Changelog documents shared storage headers, CSV `columns()`, rollback, adapter delete support, and Cloudinary cleanup credentials.
- [x] Changeset marks affected public packages for a minor release.
- [x] Managed package versions are bumped by `pnpm changeset version`.
- [ ] CI is green on the release branch.
- [ ] Publish after final maintainer review.

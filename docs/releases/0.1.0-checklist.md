# Uplift 0.1.0 Release Checklist

Use this as the final gate before publishing the first OSS npm release.

## Required Checks

- [ ] `pnpm install`
- [ ] `pnpm check`
- [ ] `pnpm bundle:size`
- [ ] Review `docs/BUNDLE_SIZE.md`
- [ ] Review `examples/next-local`
- [ ] Verify docs site locally or through GitHub Pages
- [ ] Confirm npm package contents with `pnpm --filter uplift pack`
- [ ] Confirm README badges, bundle-size text, logo, and OG image render

## Release Notes Draft

Uplift `0.1.0` introduces the first public API for typed upload contracts:

- fluent route builders for file constraints, auth, metadata, keys, and completion hooks
- inferred client methods for single and multiple routes
- Next.js, Hono, and Express handlers
- S3, R2, Bunny, Cloudinary, local, memory, and UploadThing-compatible storage adapters
- React state helpers over the vanilla client
- package smoke tests, docs snippet checks, bundle-size reporting, and a dogfood example app

## Manual Publish Steps

```bash
pnpm check
pnpm changeset
pnpm changeset version
pnpm install
pnpm check
pnpm --filter uplift publish --access public
```

Do not publish if package smoke install, storage adapter tests, or docs sample checks fail.

# Uplift 1.1.0 Media Release Checklist

## Packages

- [x] `@uplift-io/uplift` includes typed primary transforms, derived outputs, and client output getters.
- [x] `@uplift-io/image` is included in the workspace, package metadata, build, typecheck, docs, and smoke-pack verification.
- [x] `@uplift-io/video` is included in the workspace, package metadata, build, typecheck, docs, and smoke-pack verification.
- [x] Existing storage and framework packages keep publishing through the existing `@uplift-io/*` workspace filters.
- [x] Core remains free of Sharp, ffmpeg, and media-specific runtime dependencies.
- [x] `@uplift-io/image` creates real Sharp-backed image artifacts.
- [x] `@uplift-io/video` defaults to real ffmpeg/ffprobe processing with deterministic processor injection for tests.

## Verification

- [x] Runtime tests cover primary transforms, output success, transform failure, and output write failure.
- [x] Runtime tests cover adapter-supported rollback when an output write fails.
- [x] Type tests cover compatible transforms, incompatible transform rejection, declared output access, and undeclared output rejection.
- [x] Docs snippets include image optimization, image variants, video transforms, and video outputs.
- [x] `pnpm docs:check` verifies media snippets.
- [x] `pnpm smoke:pack` packs and installs `@uplift-io/image` and `@uplift-io/video` with the rest of the packages.
- [x] Site content describes transforms and outputs without implying hosted queues, dashboards, background jobs, or managed media infrastructure.

## Operational Notes

- [x] Output keys use `<primary-key>/outputs/<name>.<extension>`.
- [x] Any transform or output write failure fails the upload request.
- [x] Storage adapters can implement `delete(key)` for best-effort cleanup after output failures.
- [x] Video processing is synchronous during the upload request in v1.
- [x] Video hosting caveats, ffmpeg/ffprobe capability expectations, and path overrides are documented.
- [x] `@uplift-io/rich` is documented as legacy, with domain packages recommended for media behavior.

## Release

- [x] Changelog documents the 1.1.0 media transforms and outputs release.
- [x] Managed package versions are bumped to `1.1.0`.
- [x] Package READMEs and the root README agree on dependency boundaries.
- [ ] CI is green on the release branch.
- [ ] Publish after final maintainer review.

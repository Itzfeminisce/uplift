## Operational Notes

- [x] `.transform(...)` remains request-time processing.
- [x] `.transformAsync(...)` creates a background Transform Job.
- [x] `.outputs(...)` behaves the same for request-time and async transforms once a completed result exists.
- [x] `transform.done()` returns the completed async transform result.
- [x] Typed outputs are available on completed client results, route `.done(...)`, and global completion hooks.
- [x] Route listeners are best-effort and should not fail transform jobs.
- [x] Route `.done(...)` remains strict and can fail the workflow.
- [x] Original uploads are deleted by default after terminal states unless `keepOriginal` says otherwise.
- [x] Polling is sufficient for correctness; realtime updates are optional.

# Uplift 1.0.0 Release Checklist

Use this as the final gate before publishing the scoped package split.

## Required Checks

- [ ] `pnpm install --frozen-lockfile`
- [ ] `pnpm typecheck`
- [ ] `pnpm build`
- [ ] `pnpm --filter @uplift-io/tests test`
- [ ] `pnpm docs:check`
- [ ] `pnpm examples:check`
- [ ] `pnpm bundle:size`
- [ ] `pnpm smoke:pack`
- [ ] Review `docs/BUNDLE_SIZE.md`
- [ ] Review `examples/next-local`
- [ ] Verify docs site locally or through GitHub Pages
- [ ] Confirm npm package contents for every public package with `pnpm pack`

## Release Notes Draft

Uplift `1.0.0` stabilizes the scoped package architecture:

- core package: `@uplift-io/uplift`
- server subpath: `@uplift-io/uplift/server`
- framework adapters: `@uplift-io/next`, `@uplift-io/hono`, `@uplift-io/express`
- storage adapters: `@uplift-io/s3`, `@uplift-io/r2`, `@uplift-io/bunny`, `@uplift-io/cloudinary`, `@uplift-io/local`, `@uplift-io/memory`, `@uplift-io/uploadthing`
- rich builders: `@uplift-io/rich`

The main behavior change from `0.1.x` is dependency isolation. Installing the Next adapter no longer installs Hono, and using memory/local storage no longer installs the AWS S3 SDK.

## Manual Publish Steps

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm --filter "@uplift-io/*" --filter "!@uplift-io/tests" --filter "!@uplift-io/example-*" publish --access public --no-git-checks
```

Do not publish if package smoke install, storage adapter tests, docs sample checks, or example checks fail.
